- Ничего не оставлено на середине правки в момент записи этого файла.

## Не начато

- Дизайн-проход (screenshots «до/после») — отдельным промптом/сессией.
- Независимый аудит (другая модель / чистая сессия).
- `README.md` — всё ещё исходный курсовой файл, не переписан под
  инструкцию по запуску проекта и итоговый отчёт.
- Сравнение наивного и spec-прогона текстом (для README).
- Автотесты (не обязательны по минимальным требованиям, но не заведены).

## Активные инструменты

React 19.2.8, Vite 8.2.0, TypeScript 6.0.2, oxlint, react-leaflet 5.0.0 +

## Известные проблемы

- `README.md` в корне вводит в заблуждение — это ещё курсовой текст, а не
  инструкция по проекту. Кто угодно, кто попытается запустить проект по
  README прямо сейчас, не найдёт там `npm install`/`npm run dev`.
- Ветка `naive-run` не запушена — существует только локально.
- Марker-иконки на карте — `divIcon` с эмодзи, не проверялись на реальном
  устройстве с другим набором шрифтов/эмодзи-рендерингом (только Chrome
  desktop).
